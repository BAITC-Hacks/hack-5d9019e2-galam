The default advisor computes real projections locally, identifies critical gaps, summarizes effects and budget, explains synergies, ranks valid next decisions by immediate score gain, compares alternatives independently, and contrasts the player with the cached reference. The optional model receives server-computed facts and produces qualitative explanations. Unsupported recommendation pairs are discarded. ## Limitations and remaining submission risks

- A live OpenAI request cannot be verified without a configured key/model; no-key operation is fully smoke-tested.
- AI prose is qualitative, not a formal guarantee. Scores never depend on it.
- Refresh resets the plan and locale. There is no saved-session feature.
- Next-action suggestions maximize immediate gain, not every possible completion.
- The map is stylized; visual markers do not model geography or real construction.
- Native-speaker editorial review would improve the RU/KZ wording.
- The API has a simple per-process concurrency cap and input/origin checks, not durable public-service abuse protection.
- ESLint 9 is deprecated upstream but pinned to the current Next.js plugin compatibility range; lint passes.
- Browser tests require installed Google Chrome. The integrated browser tool blocked localhost, so the requested automated smoke test used an isolated headless Chrome session.
- Rebuilding the reference takes roughly nine seconds; this is done offline, and users load the cache immediately.
